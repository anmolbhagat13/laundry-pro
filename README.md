# LaundryPro

A premium laundry service landing page built with HTML, CSS, and JavaScript.

## Features

- Service catalog with 6 laundry services and pricing (INR)
- Add/remove items from cart with auto-calculated total
- Booking form with email confirmation via EmailJS
- Fully responsive design
- Smooth scrolling and active section highlighting

## Usage

```bash
git clone https://github.com/anmolbhagat13/laundry-pro.git
cd laundry-pro
```
## Project Structure

```
index.html   — Main page markup
style.css    — All styling
script.js    — Cart, booking, and navigation logic
```
